# Sim in the City — custom website starter

This is a plain HTML/CSS/JavaScript version of the one-page portfolio shown in your screen recording.

## What is already built

- Sticky navigation
- Smooth section navigation
- Hero split layout
- Selected Work
- Hotel / Food & Beverage / Experiences rows
- Instagram-collaboration logo section
- What I Create
- Get in Touch
- Responsive mobile layout
- Click-to-play video modal for Reels
- No Canva dependency

## Add your assets

Put your real files into `/assets/` using the filenames referenced in `index.html`.

The most important files are:

- `logo-mark.png`
- `logo-full.png`
- `hero.jpg`
- `creator.jpg`
- `contact.jpg`

Then add each Reel thumbnail and video using the names already listed in the HTML.

You can rename the files and update the matching `src` / `data-video` values in `index.html`.

## Run locally

Double-clicking `index.html` usually works for the images, but local video playback can be restricted by some browsers.

Best option:

1. Install VS Code.
2. Install the "Live Server" extension.
3. Open this folder in VS Code.
4. Right-click `index.html`.
5. Choose "Open with Live Server."

## Publish

The easiest path is a static hosting service such as Netlify, Vercel, or GitHub Pages.

Once published, connect your `siminthecity.com` domain through the host's domain settings.

## Important

Before launch, replace the placeholder contact email in `index.html` with your actual email and verify every video, image, link, mobile breakpoint, and accessibility label.
